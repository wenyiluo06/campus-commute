# 校园通勤提醒 🚌

一个**纯前端、零依赖**的校园通勤小助手。上传课表后，它会每天告诉你「现在该出发了」，并附上**路上耗时**和**天气提醒**——让你不再因为算错时间或忘看天气而踩点狂奔。

> 专为手机浏览器设计，可「添加到主屏幕」当作轻量 App 使用。

---

## ✨ 是什么

- 上传一张课表图片，**AI 自动识别**课程名、时间、教室（无需手填）。
- 每天在对话页推送「现在出发」提醒，含高德地图**路上耗时** + 和风天气**天气建议**。
- 数据存在**你自己的设备**里（浏览器 localStorage），**不登录、不上传服务器**，完全本地化。
- 支持自然语言问答，比如「今天怎么安排通勤？」「明天第一节在哪？」。

---

## 🚀 三步上手

### 第一步：首次配置
打开首页（首次使用会进入配置页）：

1. **① 上传课表**：点击或拖拽课表图片（JPG / PNG），AI 会自动识别。
   - 如果你之前导出过备份，也可以点 **「📥 导入课表（备份）」** 一键恢复，免重新上传。
2. **② 默认信息设置**：
   - **学校名称**（有分区的请把校区一起写上，例如「北京大学昌平校区」）—— 影响地图定位准确度；
   - **学期第一周的周一日期** —— 用来算现在是第几周，判断单双周 / 起止周次；
   - **默认出发地**（宿舍 / 家）；
   - **通勤方式**：步行 / 骑行 / 校内公交；
   - **天气提醒**开关。
3. 点 **「保存并进入 →」**，识别结果会在对话页里以核对卡的形式和你逐行确认。

### 第二步：每天看提醒
进入对话页后，智能体会按时间顺序列出今天的上课安排：

- 每节课一张卡片，显示 **课程名 / 开始时间 / 教室位置 / 路上耗时**；
- **第一条（时间最早）的课程卡**还会额外显示 **天气提醒** 和 **「🚶 现在出发」** 按钮——点一下就能确认该出发了；
- 前面的课结束后，次条会自动升为「第一条」并重新拉取天气。
- 也可以在底部输入框用自然语言提问，例如「今天怎么安排通勤？」。

### 第三步：随时改课表 / 备份
点顶栏 **⚙️ 设置**，你可以：

| 功能 | 说明 |
|------|------|
| 🖼️ 课表更改 | 上传新图片，重新识别课表 |
| 📋 课表预览（可增删改） | 直接查看 / 编辑正在用的课表：改课程名、教室、时间、周次，也能增删行，**改动即时保存** |
| 默认信息 | 改学校、学期起点、出发地、通勤方式、天气开关 |
| ⬇️ 导出备份 / ⬆️ 导入备份 | 把「课表 + 设置」存成一份 JSON，换设备或清缓存后一键恢复 |

---

## 💾 数据备份与恢复

- **导出备份**：在 ⚙️ 设置 → 数据备份，点「导出备份」会下载一个 `campus-commute-backup-*.json`。
- **导入备份**：点「导入备份」选择该 JSON 即可恢复（会覆盖当前课表与设置）。
- 首次配置页也提供了 **「📥 导入课表（备份）」**，和这里的备份文件通用。
- 备份文件只是普通 JSON，**建议妥善保存，不要发到公开地方**（里面含你的课表与设置）。

---

## 🔒 隐私与数据安全

- **数据只在你本地**：课表、设置都存浏览器 localStorage，没有账号、没有云端同步、不会上传到任何服务器。
- **API 密钥不上传**：高德 / 和风 / 智谱等密钥已抽离到本地配置文件，公开仓库里只有占位符，不会泄露。
- **重置**：顶栏「重置」会清空本机全部通勤数据（**含课表**，不可恢复），请谨慎操作；重置**不会**清空每日调用额度。

---

## 🛠 本地运行 / 部署（开发者）

纯静态站点，**无需构建**，直接用任意静态服务器打开即可：

```bash
# 例如用 Python 起一个本地服务
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

> **密钥配置**：仓库内的 `assets/js/config.js` 使用占位符（`YOUR_AMAP_KEY` 等）。
> 本地运行真实功能时，请新建 `assets/js/config.local.js`（参考其格式，已被 `.gitignore` 排除）
> 填入你自己的高德 / 和风 Key 与智谱代理地址；不填则自动进入 Mock 模式，逻辑照样可演示。
> 详见 `config.js` 顶部注释与各平台申请入口。

代理端（智谱 GLM 识别走服务端，前端不暴露 Key）见 `proxy/cloudbase-http/`。

## ❓ 常见问题

- **识别不准？** 课表图片尽量清晰、横平竖直；识别后可在 ⚙️ 设置 → 课表预览里逐行修改，或在对话里直接说「第 3 节教室改成 XX」。
- **天气 / 路上耗时显示「—」或模拟值？** 多半是没配置对应 Key，或当天调用额度已用完（每人每天外部 API 上限 40 次）。
- **换手机 / 清了缓存？** 用「导出备份」先存一份 JSON，在新设备上「导入备份」即可。
- **想重新来过？** 顶栏「重置」清空本机数据并回到首次配置。
