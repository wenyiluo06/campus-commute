🔑 Key 申请与配置

高德地图：lbs.amap.com → 控制台 → 应用管理 → 创建应用 → 添加 Key（服务平台选「Web服务」）

和风天气：qweather.com → 注册 → 控制台 → 项目管理 → 创建应用（选「Web API / 免费开发版」）

拿到 Key 后填入 assets/js/config.js 的 window.AMAP_CONFIG.key 与 window.QWEATHER_CONFIG.key，刷新本页即可联调；两个 Key 均已实测支持浏览器跨域直连。
